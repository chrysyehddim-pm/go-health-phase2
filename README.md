本資料夾是延續 Phase 1.2 `gohealth_handoff/0925` 視覺與健康點流程的可部署靜態 HTML Prototype。主導覽為「首頁｜紀錄｜健康圈｜任務｜探索」。產品畫面採正式服務文案；下列技術邊界供工程與驗收使用。

## 啟動

在此資料夾執行 `node dev-server.cjs`，開啟 `http://127.0.0.1:4175/index.html`。如連接埠已使用，可先設定 `PORT`。部署至 Vercel 或其他靜態主機時，上傳產品 HTML、`assets/` 與 `images/` 即可，無建置步驟。`dev-server.cjs`、`qa/` 和 Markdown 文件屬本機開發與交付資料，不應作為公開產品入口。

## 產品路徑

| 頁面 | 內容 |
| --- | --- |
| `index.html` | 問候語、通知、健康點卡、AI 提醒、紀錄、任務、健康圈與探索入口 |

所有主要頁面與兌點、腦健康子頁預設使用高齡友善大字，不顯示字級切換按鈕。健康圈可用邀請碼 `00000` 體驗已有成員的情境；也可自行建立空健康圈。近況動態先顯示最新 5 篇，每次載入更多增加 10 篇，展示最近三個月最多 100 篇，依今天、昨天、近七天及更早分組。探索頁可選「探索台北市」直接展示地圖，或自行允許瀏覽器定位。

## 資料與串接邊界

- 會員、群組互動、健康紀錄、裝置連結、遊戲參與、點數交易與通知目前存在瀏覽器 `sessionStorage`，只在同一分頁的本機體驗中保留。正式上線需接會員、健康裝置、圈內資料、任務判定與點數交易服務。
- 健康圈任務以最近 7 天已授權的裝置紀錄及成員達標數判定，並限制每項任務領點一次。本版成員資料為展示情境；正式版須由後端驗證本人與其他成員的資料、權限及發點冪等性。
- 個人遊戲連至外部網站。家事達人連結已更新為指定網址；外部遊戲完成事件與健康點入帳尚未串接。100 筆遊戲參與紀錄為頁內展示資料。
- 「推薦」是依文章主題與頁內紀錄排序的前端規則，正式個人化模型、審稿及文章更新流程尚待實作。文章索引源自亞東醫院提供的試算表，完整文章連結至院方網站。
- Google Maps 使用提供的展示金鑰載入地圖及 Places Nearby Search；請在正式部署前使用受限金鑰、設定網域與 API 限制並監控用量。瀏覽器金鑰本質上會出現在前端。地點分享會新增本分頁健康圈貼文；不會向其他會員送出訊息或座標。
- AI 提醒是依頁內數據產生的規則文案，不是醫療診斷。正式 AI 服務需另外驗證資料授權、內容與安全性。
