## 個人健康建議
- 首頁是固定入口，不在首頁直接呈現數據判讀；進入內頁才向既有HAPPY GO橋接更新資料。
- 前七個完整日期、台北時間、不含今天。每天採資料來源最後一筆每日摘要，缺漏不補零，每項各自至少三天有效資料才有個人回饋。睡眠需每日總時數標記；心率需區分靜息；運動來源應提供去重後每日總分鐘。
- 七種情境：未授權、部分授權、授權無資料、少於三天、符合提醒條件、維持習慣、更新失敗。這些可依不同指標並存，非七種互斥會員身分。
- 步數：有效日平均低於5000為產品走動鼓勵門檻，不是醫學標準。
- 睡眠：有效日平均低於7小時為休息建議；不由時數推論睡眠品質。
- 運動：中等強度分鐘+2倍高強度分鐘；150分鐘以上肯定累積。不足150只有在七天均有完整資料時才提供不足目標的建議；部分天數只呈現已記錄總量。缺少強度則不宣稱符合WHO建議。mixed類型需另外提供moderateMinutes/vigorousMinutes；light不納入等量分鐘。
- 心率：靜息資料至少三天，其中至少兩天>100或<60次/分，提醒休息後確認與必要時尋求專業建議，不診斷、不保證區間內就是健康。一般心率或不足三天靜息紀錄只提供量測情境建議。兩天次數門檻是產品草案，上線前需醫療端審閱。
- 體重：至少三天才比較最早與最近紀錄，差值取一位小數；相同或改變均採中性文案，不訂減重目標或異常增減門檻，不將短期增減判為好壞。
- 每個判讀分支有三句文案，以台北日期固定選句；當日同資料不隨機跳動。優先心率需確認的建議，再輪替其他觸發建議，再一般維持建議。主要呈現一則，其餘以主動展開查看。
- 未授權/資料不足提供一般建議與連接入口；錯誤保留前次資料與時間，超出觀察期間的紀錄不硬用。與家人關心提醒分開，不自動向家人發布個人建議。
- 本地原型以固定資料與文案池模擬，無新增LLM服務呼叫。正式資料與背景同步需HAPPY GO App開發橋接。

## 每週五種共同任務
台北時間週一00:00至週日23:59:59；每項需兩位不同成員各自完成。
1. 雙人步行接力：至少一天達5000步；300健康點/人。
2. 一起動一動：期間累積15分鐘運動；200健康點/人。
3. 一起動動腦：三個不同日期各完成至少一款遊戲；300健康點/人。
4. 全家活力週：同一成員須同時有一天6000步、累積15分鐘運動、三個不同日期有有效睡眠總時數紀錄；500健康點/人。不要求睡滿特定時數。
5. 一起記下心情：三個不同日期各新增至少一筆心情日記；不要求分享。新增任務暫用200健康點/人，屬Prototype配置，正式獎勵可調整。
- 運動依每日摘要加總，同日重複同步不重複累加；資料來源需先去除重疊運動。
- 新心情日記保存createdAt，依實際建立日期計算三天，修改時間不增加完成天數；舊版示意資料缺createdAt暫依原日期相容。
- 團隊達標且本人完成後，需主動領獎，每人每期一次；後續完成者可在期間內領取，非先到先得。
- 新加入成員可使用本期內符合條件的自身資料；任務截止後下架，未領不補，歷史明確區分已領、符合資格未領、個人完成但團隊未達標。
- 成員圓形頭像、狀態文字與補充說明分行。規則變更後本期未領的舊版全家活力週進度重新判讀，已領獎勵不扣回。
- 心情任務沿用既有日記插畫，無新增素材相依。

## 健康圈位置入口
放大圓形頭像、姓名與位置狀態。已分享位置者有地標；24小時內有效位置以品牌漸層圈提示，1至7天為較早位置。超過7天、撤回或無資料不顯示可用地圖。不宣稱在線或即時追蹤。可用位置點頭像直接進位置頁；否則開近況或本人的分享設定。查看所有成員/管理入口仍保留。S08含近期與較早位置供比較。

## 探索與文章
- 選位置後自動搜尋目前分類；初次為公園步道，家人附近為健康飲食。一次只搜一類，切回同座標同分類沿用當前頁已有結果。
- 定位未授權不阻止行政區選擇。示範空結果僅用於初始畫面，改選地區或分類後依新條件搜尋，不永久鎖成空資料。
- 範圍與最多10筆沿用既有Google搜尋；示意資料清楚標註，不偽造Google評分或營業時間，缺欄位不顯示。示意清單改成名稱/地址/類別及查看入口的緊湊版型。
- Google UI Kit正式清單仍由Google元件呈現。未啟用API或失敗時不偷換為示意資料。
- 亞東醫院LINE與遠距服務只在健康文章頁籤，附近去處及家人附近不顯示。
- 全部文章預設依日期；新增熱門分類，Prototype固定示意前三篇並標示為示意。正式依前30個完整台北日期的前往閱讀事件，每會員/文章/日去重一次，每日重算，前三篇；同分可依較新日期再文章ID排序。點選彈窗本身不算閱讀，點前往閱讀才記錄。本地只示範去重事件，跨會員排名與每日批次需後端實作。
