# 問候語、健康建議及每週完成狀態

## 首頁問候語

- 原文及台北四時段維持既有規則，僅依語意分成兩行副文案。
- 左側文字區約半幅（可用寬度 52%，上限 176px）；主標 26px、副文案 20px，小於等於 360px 時為 24px／18px。
- 通知鈴鐺獨立定位；短螢幕保留至少 210px 主圖可視高度，內容仍用整頁捲動、圓角白卡。
- 男女共八張圖檢查 320、390、430px 寬度，不裁切問候文字。

## 健康建議

- 有生活調整建議的卡片先顯示，再顯示維持習慣／持續紀錄卡片。
- 同類型依步數、睡眠、運動、心率、體重固定順序，不強制心率第一。
- 各指標判讀、資料期間及日期穩定選句不變，循環疊牌操作不變。

## 本人本週五項皆已領獎

- 首頁與健康圈摘要顯示「本週任務獎勵都已領取，謝謝你和家人一起完成。」及查看全部入口，停止推薦已領卡片。
- 依本人領獎紀錄判斷，不以全圈所有人是否領取為條件。任務中心仍保留當期任務及個別成員進度。
- 健康圈摘要先選可領獎任務，再選固定順序的未領任務。
- S12 整併 `taskCase=all-claimed`，可從首頁或健康圈檢查，不增加導覽情境編號。
