# 2026-10-20 心情紀錄與健康圈留言規則

## 心情紀錄
- 新增只選心情及輸入文字，不提供日期或時間控制項；提示儲存時會自動記下時間。
- 儲存成功時以同一個時間點建立createdAt（UTC ISO），再衍生台北時間的date與time。開啟表單不先鎖定時間，跨午夜仍依儲存時間歸日。
- 事後僅可編輯note文字，不接受表單傳入的心情、日期、時間。變更文字才新增/更新editedAt，介面顯示已編輯；排序、心情樹與任務仍依原始建立時間。
- 舊資料若沒有createdAt，保留既有日期與時間，不在編輯時改寫為現在。新紀錄依createdAt含秒數排序，避免同分鐘多筆無法選出最新心情球。
- 既有健康圈貼文是分享時的快照，不隨私人日記文字修改。
- 從健康圈分享心情並勾選同時存日記，也使用相同建立時間邏輯。
- Prototype使用瀏覽器當下時間；正式版需以後端建立時間為準，後端同樣拒絕更改原始心情與建立時間，僅開放文字修改。

## 健康圈留言
- 主清單仍為原貼文最近七天、最多20筆；留言不占貼文筆數。
- 貼文卡僅顯示留言總數按鈕，不展開長串文字；點選後進入獨立留言視窗。
- 初次顯示最新3則，選出的留言依舊到新排列；查看更早留言每次增加10則，保持輸入中的草稿。
- 新留言最多150字，空白不能送出；罐頭關心與自行輸入套同一規則。UI maxlength與送出檢查雙重限制，送出期間停用按鈕避免重複。
- 不設單篇留言總數上限，也不因顯示限制刪除留言。舊版超過150字的既有內容保留。
- 新留言保存id與createdAt，顯示台北時間。舊留言缺時間時顯示先前留言，不捏造時間。
- 發布留言不修改原貼文createdAt、不改動貼文陣列順序。超過七天貼文離開主清單，原貼文與留言仍保留，不提供新歷史入口。
- 留言會檢查目前仍屬同一健康圈、原貼文仍存在；正式跨會員權限與發送冪等性需後端實作。
