# 2026-10-20 每週家人關心、任務資格與刪除功能

本輪依產品確認更新 Prototype 與情境導覽，並依部署指示納入 GitHub 發布。本輪未回寫 Google Sheets 或覆寫功能簡報；通知、排程與發點仍為 Prototype 模擬。

## 家人關心摘要

- 台北時間每週一 00:00 為週期起點，睡眠／步數採上週一至週日。
- 加入健康圈滿七天才判斷七天未使用 GO HEALTH／未完成遊戲。當週回來使用或完成遊戲，解除對應原因，不立即重新產生當週參與原因。
- 睡眠與步數各自至少五個有效完整資料日，其中至少三天睡眠少於七小時／步數少於 5,000。睡眠需每日總時數標記，年齡與步數適用性沿用既有保護。不將資料缺漏當成零。
- 同一人、同一圈、同一週只有一張卡，多個原因合併。同週每位家人最多一則通知。
- 健康原因是上週回顧，不因今天走多或睡足立即移除；若來源補正使上週不再符合，更新該原因。晚同步可補算同一份摘要，不重複通知。
- 個人按傳送關心後，訊息會出現在圈內近況，卡片只在自己畫面收合到「本週已關心」。其他成員仍可關心，不把已傳訊息當作健康恢復。
- 所有原因解除、本人撤回同意、離開／移出圈時，該圈不再顯示卡片。下一週重新判斷，符合就建立新週摘要，已關心狀態不跨週。
- Prototype 在載入或操作時，以當週起點模擬後端週摘要；沒有實際背景排程、跨會員傳送或 App 推播。正式需後端計算及站內通知服務。

## 共同任務

- 保持每週一至週日、五種任務、每項兩位不同成員完成。
- 任務只計本期資料，不用前週行為重複取得本週資格。新加入仍可採本期自身有效資料。
- 個人完成資格保存於會員／任務／週期，與圈別分開。停止讀取、刪除已使任務達成的日記，不回退已成立資格；尚未完成前刪掉的日記不再用於未來累積。
- 團隊每次依目前成員計數。退出或移出者不計入；少於兩人重新鎖定。新加入者若符合，仍可重新解鎖。
- 領獎以會員／任務／週期防重，不因換圈增加次數。已在 A 圈領過，加入 B 圈可協助解鎖但不能重領。
- 已成功入帳不因後續團隊重新鎖定而撤回，歷史保留已領結果。
- 參與紀錄不直接領獎，僅保留當期任務的查看／返回入口，領獎在任務中心詳細頁。
- 一次只能在一個圈，建立／加入會檢查目前會員狀態。正式邀請碼規則、原子發點、跨會員權限仍由後端實作。

## 刪除

- 私人心情日記：本人可刪，確認視窗說明不可復原及分享快照獨立。樹洞改取當天剩餘的最新一筆，日記列表與筆數同步更新。已分享到圈內的貼文不連動刪除。
- 健康圈貼文：只顯示本人貼文的刪除入口；確認後，該篇及其附屬留言一同不再顯示。原始私人日記不受影響。
- 留言：只能刪自己的留言，其他留言保留，總數同步更新。取消或確認刪除後均保留正在輸入的草稿與已載入筆數。
- 圈主不增加刪他人內容的權力，不加回收桶或還原功能。正式刪除／保存政策與伺服器權限另行實作；原型操作的是本分頁模擬資料。

## 授權與條款

維持健康資料、家人關心、最後位置分享各自說明與開啟。探索定位不等於分享給家人。健康指標全選仍只作用於健康讀取項目。

本輪更新家人關心的功能說明，不把新用途默認併入已同意的服務條款；完整條款增補及是否補充同意待法務審閱後處理。

## 情境導覽

維持 S01–S18，不增加主卡片：

| 情境 | 本輪檢查入口 |
|---|---|
| S05 | 五人成員管理、多則留言、刪自己的貼文／留言 |
| S07 | 本週摘要、家人返回後原因解除、新一週仍符合；可實際傳送關心查看本人收合 |
| S11 | 領獎流程、停止讀取後保留已成立資格 |
| S12 | 已領獎、換圈後協助解鎖但不重領 |
| S13 | 獨立參與紀錄，無直接領獎按鈕 |
| S14 | 五人五任務排版；以圈主移出已完成爸爸，檢查重新計數 |
| S15 | 同日多筆、已分享日記、刪除及心情樹最新球替換 |

S07／S11／S12／S14 的延伸連結整併在原卡片，無產品頁下拉切換器。情境參數會重設本分頁資料；進入後移除參數，普通重新整理保留結果。

## 驗證

`qa/weekly-rules.cjs` 使用可控制的台北日期驗證：週一與上週範圍、五有效日／三低值日、參與原因解除、每人收合、晚同步防重、跨週重新通知、撤回同意、跨圈同週唯一領獎、移除重新鎖定、新成員重新解鎖、已發點保留、日記刪除與獨立快照、留言草稿及本人刪除權限、320／390／480px、18 張導覽卡與子流程。

執行環境需 Node.js、Playwright 及 Edge，範例：`NODE_PATH` 指向內建 Node 套件後，執行 `node qa/weekly-rules.cjs`。本機預設 `http://127.0.0.1:4175/`，可用 `PROTOTYPE_URL` 指向其他測試服務。
