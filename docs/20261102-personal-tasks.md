## 正式資料對接

Prototype沿用既有 `GH.state.gameHistory` 的成功完成資料，亦提供 `GH.state.personalTaskCompletions` 陣列作正式完成資料的對接位置。這不是已完成的DB連線。

建議完成紀錄格式：`{ taskId: 'focus', completed: true, completedAt: '2026-11-02T02:00:00Z' }`。

- 任務ID：問卷 `health_start`、幸福柑仔店 `ad8`、眼力 `focus`、生活好時光 `memory`、一日店長 `shop`、家事達人 `house`、健康小學堂 `school`。正式API若ID不同，請在接收資料時明確轉換。
- 成功旗標為 `completed:true` 或 `status:'completed'`；失敗、僅開始、待處理不計。既有示範紀錄可用完整任務名稱比對；正式串接優先使用ID。
- 日期可用已按台北日結算的 `date:'YYYY-MM-DD'`，或帶時區的 `completedAt` 時間戳；不可直接將UTC日期當台北日期。
- 完整期間紀錄需由會員資料服務提供：每日當日、每月當月、問卷當半年。不可僅由最近100筆遊玩紀錄推斷正式會員的當期資格。
- 接收可信來源的完成資料後，透過既有 `GH.set(s => { s.personalTaskCompletions = rows; })` 更新。此處只控制顯示，不執行發點；後端仍負責資格、完成與點數帳務。
