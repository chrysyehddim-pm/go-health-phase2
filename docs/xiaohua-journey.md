## 展演順序與要帶出的價值

|順序|操作|可以這樣說|
|---|---|---|
|1 首頁|先看家庭、建議、紀錄與健康點|小花 45 歲，平常忙於生活，也掛念爸媽。首頁讓她一眼知道家人的近況，以及今天可以為自己做什麼。|
|2 健康建議|進入並翻動建議卡|健康數字不容易理解，因此把前七天的紀錄整理成生活建議，幫助會員從一件做得到的小事開始。|

|4 私人分享|選一筆日記，勾選是否附文字、預覽、發布|日記預設私人，小花決定分享哪些內容；陪伴從她願意說的一句話開始。|

## 展示資料與操作

- 圈主吳小花 45 歲，成員為老公 47、爸爸 72、媽媽 69、女兒 20；親友關係僅圈主管理時顯示。
- 採用現有品牌插畫頭像；首頁性別為女性，問候語與背景依臺北實際時間切換。
- 五項指標已連接，紀錄涵蓋最近 30 天。睡眠取完整前日、體重非每日量測；更新健康資料仍使用這份情境資料。
- 心情 22 個日期共 23 筆，包含同日多筆；新建、編輯、分享、刪除均沿用現有規則。
- 爸爸在展示建立前 18 分鐘更新板橋車站附近；老公為兩天前的位置；其他人未分享。開啟自己的位置分享也使用板橋示意位置。
- 媽媽的上週睡眠符合關心條件；關心仍沿用既有同週收合規則。
- 本週步行由小花與爸爸達標，可領取 300 點；其他任務依真實週期與展示資料計算，週一、週二不虛構三天完成紀錄。
- 初始健康點 1,200，領步行任務後 1,500，兌換 1 點 HAPPY GO 後餘額 1,000；不異動任何真實帳戶。
- 本人探索預設板橋車站（25.0142, 121.4638）、公園步道；家人附近搜尋預設健康飲食，皆使用現行 Google 搜尋與清單，不使用舊示意清單。
- 地圖需網路與有效 API 設定；載入失敗沿用重試／外部 Google 地圖入口，不補造營業資料。
- 每頁的「旅程導覽」可查看順序、目的、重新開始；這是展示工具，不是產品正式操作選單。
- 資料保存在目前分頁的 sessionStorage，切頁、返回與重新整理皆保留。同一網址在不同手機各自建立獨立資料；關閉分頁後可能重新開始。
